# Justdeuspi

Boutique en ligne de luxe — Vêtements & Cosmétiques

## Stack
- Next.js
- Convex
- Tailwind CSS

## Logo
Le logo choisi est le style moderne violet/bleu.

## Comment continuer
1. Clone ce repo
2. `npm install`
3. `npx convex dev` (choisis le projet justdeuspi)
4. `npm run dev`

## Structure
- `convex/schema.ts` → Base de données
- `convex/products.ts` → Fonctions produits
